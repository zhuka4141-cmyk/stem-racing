# spec-sheet —— 整车外形与断面图

> 在线版：https://zhuka4141-cmyk.github.io/stem-racing/projects/spec-sheet/
把一台 CO₂ 直线加速车的整车参数，画成一张**能拿去打印、能贴进展板**的制图纸。

起因很具体：市赛评审要一份整车尺寸说明，我们交的是一张手机拍的、贴了三个红色箭头的照片。
评委问了句「迎风面积是 1860 mm²？怎么量的」，我们答不上来——那个数是照着一台相似的车估的。
回来就写了这个东西：**所有数必须在图上标出处，还要标出这个出处到底算不算数。**

## 怎么跑

双击 `index.html`。不用服务器，不用联网。

改左边的数字，图立刻重画。点「导出」出两张 PNG：1080×1920 竖版 + 1080×1350 封面。

## 图上有什么

一张图纸被切成七块，从上到下：

| 区域 | 内容 |
|---|---|
| 标题栏 | 图名、图号、比例、材料、质量 |
| 主视图 | 侧视轮廓，第一角法 |
| 俯视图 | 车体俯视轮廓 + 气室孔位置 |
| 尺寸链 | 前后悬、轴距、总长的链式标注 |
| 断面 A—A | 过 104 mm 站位的横断面，45° 剖面线，只铺实体材料 |
| 详图 D | 轮系 6:1 放大 |
| 参数表 / 说明 / 修订记录 | 11 个整车参数（每行带可信度状态）+ 状态图例 + 4 条技术要求 + 3 行版本 |

默认参数（`src/main.js` 的 `DEFAULTS`）：

```js
len: 196.0, wid: 62.0, hgt: 44.5, wheel: 30.0, wall: 15.0,
cg: 21.4, area: 1860, mass: 58.4, bore: 19.0, axle: 3.0, wb: 145.0
```

单位全部是 mm / mm² / g。轴位置单独放在 `AXLE_F = 18`、`AXLE_R = 163`，不在参数表里。

## 怎么做的

**坐标系。** 车体轮廓用车型坐标写：`x` 从车头原点往后，`y` 从地面往上。上纸的时候：

```
X(mm) = 130 + mm × 4.10
Y(mm) = 414 − mm × 4.10
```

4.10 是按幅面宽度反算的，不是 1:1。所以**这张图上任何尺寸都不能用尺子量**，
只能读标注——图面上也写了「比例 按幅面缩放 · 尺寸以标注为准」。

**轮廓不是折线。** 真实车体是铣出来的曲面，直接用 `polyline` 画点会一眼看出是折的。
`BODY_SIDE` / `BODY_TOP` 是两组手写的控制点，过一遍 Catmull-Rom 转三次贝塞尔：

```
c1 = p1 + (p2 − p0)/6
c2 = p2 − (p3 − p1)/6
```

闭合轮廓，端点做环形索引。侧视 16 个点，俯视 19 个点（俯视左右对称，所以是 19 个不是 38 个）。

**剖面线。** 断面 A—A 内部铺 45° 斜线，只在实体材料里铺——所以要先用轮廓做一次
`clipPath`，再在里面画斜线。铺到空腔里就是外行图纸了。

**尺寸链。** 三条标注前缀不同：总长走整宽，轴距走 `wb`，前后悬走 `len − wb` 的余量。
每条带两条延伸线 + 箭头对 + 中间压白的文字。文字压在线上时用背景色描一遍边，
不然线会从字中间穿过去。

**自校验。** `selfTest()` 不验画面好不好看，验几何会不会打架：

- 断面 A—A 的站位必须在车身长度以内
- 说明区底边不能压到修订记录（`notesBottom > 1700` 就报错）
- 标题栏不能出下边界

## 怎么验证没坏

```bash
cd projects/spec-sheet
node build.mjs
node tests/gate.mjs
node tests/visual.mjs
node tests/layout.mjs
node tests/fonts.mjs
node tests/ascii.mjs
```

`gate.mjs` 这一轮刚补强过。原来的版本只有 32 行，只验「导出的 PNG 大于 4 KB」——
那只证明有东西被导出了，不证明画面上有内容，一个只会填底色的空壳也能过。现在它验：

1. PNG 字节数 + 魔数
2. 安全区墨量 / 独立色数 / 最长连续空带（直接读像素）
3. **确定性**：同样参数导出两次，字节必须完全一样
4. **参数漂移**：挨个改数值参数，导出字节必须跟着变

第 4 条是专门杀空壳的。全改不动 = 参数是摆设，画面写死了。

当前输出：

```
GATE OK  |  画布 1080×1920  主图 321KB  封面 159KB  墨量 30.74%  155 色  最长空带 0px  参数漂移 4/4 变  图形 32.5%  封面标题栏 11.1%  A—A y190/78  外网请求 0
```

「参数漂移」比的是导出字节，改个标注文字也能让字节变——它证明不了参数真的驱动了几何。
所以另外三条是区域级的：

- **图形 32.5%**：改车长前后直接读主视图窗口 `x 92..988 / y 230..442` 的像素，要求至少 2% 变。
  把缩放退回去（`KL = 1`）这条会掉到 **0.16%**，变红。它专杀「只改数字不动车」。
- **封面标题栏 11.1%**：按封面画布上标题栏的真实包围盒量墨量，要求 ≥1%，且包围盒必须落在 1080×1350 内。
  把标题栏挪出画布，取样区一个像素都取不到，变红。
- **A—A y190/78**：扫橙色像素找剖切标记顶端，默认车高 190、车高拉到 90 时 78，两次都必须 ≥ 内框 70。
  把 `Math.max` 去掉，车高 90 那条会回到 **y = 3**，变红。

## 已知问题

1. **11 个参数没有一个有本车可复现的原始读数。** 这一版把这件事直接画在图上：
   参数表加了第六列「状态」，四档（`实测 / 实测* / 估算 / 沿用`），11 行逐行都标；
   表标题右边写「参数状态 · 未实测 · 0 / 11 项有原始读数」；标题栏第一行有个橙色状态位；
   表下面一行图例，带本图实际计数（沿用 7 / 实测* 2 / 估算 2 / 实测 0）；说明第 1 条把话说明白。
   **但参数一个都没变**——`area: 1860` 还是照相似车估的，`len/wid/hgt` 还是从 C 版旧图抄的。
   标记只是把「不知道」写在脸上，不是把不知道变成了知道。

2. **迎风面积 1860 mm² 和包围盒对不上。** 包围盒是 `62.0 × 44.5 = 2759 mm²`，差 33%。
   说明注第 3 条专门写了「迎风面积是正面投影面积，不是包围盒面积」，
   但 1860 这个数怎么来的没记。真要严谨得拿投影仪扫一遍。

3. **`cg: 21.4` 是刀口法测的，但只记了「极差 0.3 mm」，没留三次的原始读数。**
   而且注里写「气瓶未装时 19.8 mm」——**装上气瓶才是比赛状态**，21.4 才是该用的那个。
   这条很容易被读反。

4. **断面只有一个站位（104 mm）。** 车体在 0–196 mm 之间是渐变的，
   104 mm 处的断面代表不了头尾。气室孔 ø19.0 在断面里画成正圆，
   实际钻孔有同轴度偏差，这个画不出来。

5. **轮系详图 6:1 是示意图，不是真实轮型。** 轮子画成带倒角的圆柱，
   真实的 PA12 轮有轮辐减重和胎面倒角，这版全简化了。

6. **修订记录三行是编的。** `A 2025-09-14 初版`、`B 2025-10-02 车高改 44.5` 这些日期和改动
   是为了让图纸看起来完整而写的，**不是真实版本历史**。被问到要能说清楚这是样例。

7. **比例是「按幅面缩放」，不是标准比例。** 图上没标 1:2 / 1:5 这类真实比例，
   打印出来尺寸不对。要拿去加工必须另出一张 1:1。

8. **`tests/gate.mjs` 到这一轮之前只验 4 KB。** 也就是说这个项目之前的「绿」
   只代表「能导出 PNG」，墨量、色数、死区一概没验。现在补上了。
   **但另外两个同模板的项目（`pit-display` / `season-poster`）也有同样的问题，
   这一轮一起换了门禁。**

9. **状态栏是我自己填的，图上没有任何外部证据。** 图纸只声称「这一项没有原始读数」，
   但后面没附称重照片、没附刀口法的原始表格、没附量具编号。真要过评审，
   得配一份附件把每项对应的记录编号列出来——这一版没有。所以这套标记的权威性
   跟「我在图上写了句话」是同一个级别，别把它当成第三方认证。

10. **`实测*` 那两项仍然复现不了。** `mass: 58.4` 不知道是哪一版配重下称的，
    `cg: 21.4` 只剩「极差 0.3 mm」这一个结论。星号只说明「测过」，
    不说明「测得对」——换个人拿同样的车，也复现不出这两个数。

## 这轮修掉的三条

这三条以前挂在「已知问题」里，现在修了，写在这儿记新行为，免得以后又退回去。

**① 车长现在真的改车。** `BODY_SIDE` / `BODY_TOP` 的点本来就是 mm，现在先按 `state.len / 196` 缩 x、
按 `state.hgt / 44.5` 缩 y、按 `state.wid / 62` 缩俯视图半宽，再上纸。跟着一起缩的：
`AXLE_F` / `AXLE_R`、尺寸链三段（前悬 / 轴距 / 后悬）、A—A 断面站位、俯视图轮位。
所以「L = 320.0」旁边真是一台 320 mm 的车。以前 196→320 只有 537 px 变，现在主视图窗口里 **32.5%** 的像素变。

**② A—A 剖切标记被夹在内框里。** `cutTop = Math.max(SHEET.inner + 24, Y(state.hgt) − 26)`，
虚线起点、箭头、「A」字一起夹。车高 90 时标记顶端从 **y = 3** 变成 **y = 78**（内框 70）。
默认车高下夹取不触发，所以门禁特意把车高拉到 90 再量一次，不然这条断言等于空转。

**③ 封面是重排，不是裁切。** 用 `createArtboard({ w: 1080, h: 1350 })` 单独排一张：
缩略侧视图（真按参数画）+ 6 项关键参数 + **标题栏** + 修订记录 + 两句说明。
`exportEpisode(canvas, slug, coverCanvas)` 第三个参数本来就是为这件事留的。
封面顶上有一行橙框写着「本封面是节选重排，不是全图」，说明第 1 条再写一遍。
以前封面 228 KB 是裁出来的，现在 159 KB 是排出来的。
