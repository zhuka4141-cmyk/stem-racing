# gear-ratio-explorer · 齿比再大一点真的更快吗

> 在线版：https://zhuka4141-cmyk.github.io/stem-racing/projects/gear-ratio-explorer/
**先说清楚：我们的 CO₂ 车没有变速器。** 气瓶直接吹后轮，中间没有任何齿轮。
这个页面是「如果装上会怎样」的假设空间，不是对现车的调参工具。

做它是因为队里一直有争论：有人说齿比越大起步越猛肯定更快，有人说齿比大了
终速上不去。两个人都对一半，而且**最优的那个值比双方猜的都靠中间**。

纯 Canvas2D 手画，三张图、四个读数、一句话结论。

---

## 一、参数化：变的只有一个 i

等效传动比 `i` 定义为「驱动侧转速 / 车轮转速」。i 越大 = 低档位 = 力大但顶速低。

我让 `i` 同时动三个量，但**死死按住冲量不动**：

```
F_peak(i) = 21 · i          N
t_burn(i) = 0.110 / i       s
v_ceil(i) = 26.0 / i        m/s

冲量 ∫F dt = 2·F_peak·t_burn / π = 2×21×0.110/π = 1.4706 N·s
```

只要 F_peak 和 t_burn 反比变化，冲量就与 i 无关——**同一份能量，换个放法**。
这是整个模型最核心的假设。如果冲量随 i 变，大齿比就等于白送能量，就比不出东西。

```
i = 0.20   F_peak =  4.2 N   t_burn = 550 ms   v_ceil = 130 m/s
i = 1.00   F_peak = 21.0 N   t_burn = 110 ms   v_ceil =  26 m/s
i = 3.00   F_peak = 63.0 N   t_burn =  37 ms   v_ceil = 8.67 m/s
```

其余参数跟 accel-curve-lab 完全一致，i = 1 时逐位退回原来那台车：

| 量 | 值 | 来源 |
| --- | --- | --- |
| 整车质量 m | 0.065 kg | `[VERIFY]` |
| 等效惯性质量 | 79.88 g | 推算 m + ΣI_w/r_w² |
| 迎风面积 A | 1.6×10⁻³ m² | `[TYPICAL]` |
| Cd0 | 0.34 | `[TYPICAL]` |
| Crr | 0.008 | `[TYPICAL]` |
| 推力峰值 / 时长 | 21 N / 110 ms | `[VERIFY]` |
| 车轮速度上限 @ i=1 | 26.0 m/s | `[VERIFY]` |

## 二、v_ceil 是什么，为什么必须留着

前两个量（力变大、时间变短）是互相抵消的。光靠它们算不出任何权衡——
冲量一样、做的功一样，末速几乎不变。真正的差别全来自第三个量：

**驱动侧能推动车轮的最高线速度是有上限的。**

物理上这个上限来自三处：气瓶在有限行程里能持续输出到多高转速、喷嘴出口速度、
以及轮子本身在这个转速下的滚动损耗。我把它折成一个数：i = 1 时 26 m/s。
超过它就推力归零，不是衰减，是断掉：

```js
export function thrust(t, v, p) {
  if (t >= p.tBurn || v >= p.vCeil) return 0;
  return p.fPeak * Math.sin((Math.PI * t) / p.tBurn);
}
```

**为什么取 26**：i = 1 那一档冲到 18.34 m/s 就到终点了，26 是「最小的、
保证不干扰 i=1 基线」的取值。这个数不是测出来的，是我为了让基线不被污染
而选的。见「我知道的问题」第 1 条。

## 三、跑出来的数

峰值加速度可以直接推：

```
a_max(i) = F_peak(i) / m_eff = 21·i / 0.07988 = 262.9·i m/s² = 26.8·i g
```

扫出来两端和几个关键档：

```
i        完赛时间     终速          峰值加速度
0.20     1.405 s     16.96 m/s      5.4 g
0.90     1.181 s        —          24.1 g
1.00     1.188 s     16.91 m/s     26.8 g    ← 现在的车
1.40     1.173 s        —          37.5 g    ← 最优点
1.45     1.199 s        —          38.8 g    ← 上限开始咬住
3.00     2.426 s      7.88 m/s     80.2 g
```

（`—` 是我没单独记的档位，不编数。）

三张图分别画 `v(t)`、`t(i)`、`v_exit(i)`。第二张是 U 形，第三张单调下降。

**最优 i\* = 1.40，完赛 1.173 s，比现在的 1.188 s 快 15 ms。**

15 ms 在 20 m 的比赛里大约 25 cm，不算小。但 i = 0.90 也能跑 1.181 s，
所以推荐带是 **i = 0.90 – 1.40**，不是一个点。

## 四、最有意思的一条：最优点卡在上限生效的前一档

扫 i 的时候两段形状完全相反：

```
i = 0.20 → 1.40    时间随 i 严格下降    ← 推力不够，加大齿比有用
i = 1.45 → 3.00    时间随 i 严格上升    ← 速度被顶死，加大齿比只剩坏处
```

分界点 i = 1.45 就是 `v_ceil` 第一次真的咬住的那一档，最优点 1.40 紧贴在它
左边一档。

物理上说得通：**上限没生效时，多出来的推力是净收益；上限一生效，多出来的
推力就只剩下「更早顶死」这一个作用。** 最优解必然落在上限生效的门槛上。

图上把 i > 1.45 这一段用底纹加虚线单独标出来，标着「速度上限生效 i > 1.45」。
不标的话，右半边那段上升很容易被当成模型抖振。

也正因为如此，`gate.mjs` 是**分两段验单调**的，不是只验一个整体 U 形：

```
✓ 速度上限在一个明确档位开始生效  →  i > 1.45
✓ 未顶上限段：时间随 i 严格下降  →  i 0.20→1.40：1.405→1.173 s
✓ 顶上限段：时间随 i 严格上升    →  i 1.45→3.00：1.199→2.426 s
✓ 最优点就落在上限开始咬住的位置（±1 档）  →  i*=1.40 · 上限起点=1.45
```

## 五、其余断言

- i = 1 的完赛时间 = 1.1885 s、终速 = 16.906 m/s（必须等于基线，±4 ms）
- 终点位移 = 20.00 m ± 0.05
- 等效惯性质量 79–81 g
- 冲量 = 1.4706 N·s，且 i = 0.4 / 1 / 2.5 三档各自算出同一个值（±1e-9）
- 终速随 i 单调不增（容差 1e-6）
- 小齿比更慢（1.405 s）、大齿比更慢（2.426 s）
- i = 3 必须撞上限（8.67 m/s），i = 0.3 和 i = 1 必须不撞
- 推荐带包住最优点
- 拖动传动比后曲线区域的像素哈希真的变了

## 六、修过的一个真 bug

第一版扫 i 时 gate 报 `到头速度不随 i 单调下降，断在 i=2.85`。
整体是从 16.96 降到 7.88 的，但在 2.85 那一档翻上去了。

我先怀疑是 `v_ceil` 的硬截断造成的——不是。**是积分器终点判定的量化误差。**

```js
// 错的：x 冲过 20 m 才停，终点时间被 dt 量化成台阶
v += a*dt; x += v*dt; t += dt;

// 对的：跨过 20 m 的那一步做线性插值
if (xN >= DIST) {
  const f = (DIST - x) / (xN - x);
  t = t + dt*f;  v = v + (vN - v)*f;  x = DIST;
}
```

同时把扫描步长从 `1/3000` 收到 `1/12000`。改完两段单调性都恢复，断言一条没放宽。

（顺带修了第二个：图表①的 x 轴改成随当前档位缩放后，跑得更久的参考曲线
被画到了画布外面。补了 `ctx.rect(...); ctx.clip()`。）

## 七、我知道的问题

1. **V_CEIL_REF = 26 m/s 是我为了让基线不被污染而选的自由参数。** 整个高齿比
   段的悬崖形状完全由它决定。取 20 就会把 i = 1 截断、基线作废；取 40 最优点
   会右移。这个数没有任何实验支撑。

2. **真车没有变速器。** 这一页全部是假设。真要落地得先造一台带齿轮箱的车，
   而 CO₂ 车的规则多半不允许。

3. **忽略了齿轮箱自己的转动惯量。** 加了变速器就有额外的齿轮、轴、轴承，
   等效惯性质量会随 i 变。模型里 MEFF 恒为 79.88 g，与 i 无关。真实情况
   i 越大反射惯量越大，会进一步惩罚高齿比——真实悬崖可能更陡。

4. **冲量守恒这个假设本身可疑。** 换齿比不会改变气瓶的总做功能力，但会改变
   工作点效率。我假设 `∫F dt` 严格不变，等价于假设「不管怎么放，能量一样多」。

5. **`v_ceil` 的硬截断让加速度不连续。** i > 1.45 时加速度在某一刻从正值直接
   跳到负值。真实的气动/机械衰减是连续的。这会让 t(i) 在门槛附近出现尖角，
   i\* 的精确位置（1.40 还是 1.38）受这个尖角影响。

6. **最优点和门槛只差一档，所以 i\* 的精度受扫描网格限制。** 用了 57 个点，
   步长约 0.05。真值可能在 1.38–1.43 之间。图上写 1.40，不该当三位有效数字读。

7. **没考虑侧向力和走线。** 齿比大 = 起步猛 = 更容易跑偏，这跟 mass-budget
   里的 1.32 mm 是耦合的。两个页面各自独立算，合并起来会互相打架。

8. **图表① 的 x 轴随当前档位缩放。** 好处是曲线永远填满画幅，坏处是拖动时
   横轴在动，跨档位比较斜率容易看错；跑得更久的参考线会被裁在右边缘外。
