TURBULENCE-STREAK

车尾交替甩出的涡排成两列。拖车速看频率怎么变、包络怎么张开；拖抖动看随机量怎么扰动形状。

TYPICAL种子固定
两个特征长度别混
车长 L = 0.200 m 只进雷诺数 Re = vL/ν；脱落用 车宽 D = 0.050 m， 因为 Strouhal 数定义在横流尺寸上。所以 f = St·v/D = 67.6 Hz， λ = D/St = 0.250 m。

λ 跟速度无关
这是最反直觉的一条。车速从 10 提到 20，涡街在空间上几乎不变——涡数、 间距、包络都一样，变的只有时间：每秒 34 个还是 68 个。 图里那条"脱落节拍"就是拿两倍车速并排比的。

速度只改两件事
一是频率（∝ v），二是涡核半径 r = √(4νx/u_c)（∝ 1/√v）。 低速时涡核胖、高速时瘦，这是图上唯一能看出速度的几何量。

随机量是可复现的
涡的强度抖动和横向抖动全部来自 mulberry32(0x5EED1E55)，没有 Math.random()。 同一组滑杆导出两次，两张 PNG 逐字节相同。

一个和共用内核打架的地方
共用内核算 f 用的是车长，得到 16.9 Hz，比这里小 4 倍。我留了断言盯着这个差值， 没有偷偷改内核——差异记在 README 里。
