# turbulence-streak · 车尾的卡门涡街

> 在线版：https://zhuka4141-cmyk.github.io/stem-racing/projects/turbulence-streak/
一根 CO₂ 车跑完 20 m，车屁股后面一直在甩涡。这个页面就是把那一小片尾流放大成一整张图：
上下两列涡反着转、交替脱、间距固定，然后拿滑杆去问它"车速变了会怎样"。

先把结论放前面，因为它跟直觉反着来：

**涡的间距跟车速没关系。** λ = D/St = 0.250 m，车开 10 m/s 是 0.250 m，开 20 m/s 还是 0.250 m。
速度只改两件事——每秒脱几个（∝ v），和涡核有多胖（∝ 1/√v）。

---

## 我算的东西

两个特征长度，一开始我混着用，后来发现必须分开：

| 符号 | 值 | 用在哪 |
|---|---|---|
| 车长 L | 0.200 m | 雷诺数 `Re = vL/ν` |
| 车宽 D | 0.050 m | 脱落频率、涡间距 |

Strouhal 数定义在**横流尺寸**上，不是流向尺寸。所以：

```
f  = St · v / D        脱落频率
λ  = D / St            同一列相邻两涡的间距
u_c = 0.85 v           涡往下游走的速度
```

代进整跑末速 16.906 m/s（共用内核算出来的出线速度）：

```
f  = 0.20 × 16.906 / 0.050 = 67.62 Hz   →  周期 14.79 ms
λ  = 0.050 / 0.20          = 0.250 m     →  1.25 个车长
u_c = 0.85 × 16.906        = 14.370 m/s
```

雷诺数：

```
Re_L = vL/ν = 16.906 × 0.200 / 1.516e-5 = 2.2303 × 10⁵
Re_D = vD/ν = 16.906 × 0.050 / 1.516e-5 = 5.575  × 10⁴
```

`Re_D` 落在 10³–2×10⁵ 这段亚临界区，`St ≈ 0.2` 在这个区间才是能站住的经验值。
如果拿车长去算 `Re_L = 2.2×10⁵`（图左上角标的就是这个），那是给"整个车身"用的数，不是给脱落用的。

尾流几何：

```
包络全宽  h(x) = 0.028 + 0.32 x         0 → 2.4 m 张开到 0.796 m，张角 ≈ 18°
涡核半径  r(x) = √(4 ν x / u_c)         在 2.4 m 处 3.18 mm（16.9 m/s）
```

涡核这一条是唯一能看出速度的几何量：5 m/s 时 `r = 5.85 mm`，20 m/s 时 `r = 2.93 mm`，
速度翻 4 倍核瘦一半。拖滑杆能直接看到涡团的胖瘦在变，而它们的位置一个都没动。

## 图上能看出什么

**① 俯视涡街。** 车在右边，尾流往左。橙色的下排是正涡（顺时针），白色的上排是负涡（逆时针），
两列严格交替，相邻涡沿流向隔半个波长 0.125 m。橙线标出的是同侧相邻两涡的距离，也就是 λ。
底部的虚线是包络，左端最宽。

**② 脱落节拍。** 两条刻度带并排：上面是当前车速，下面是它的一半。
同样的 0.25 s 窗口里，16.9 m/s 脱 17 个，8.5 m/s 只脱 8 个。频率差就是这样被画出来的。

**③ 频率曲线。** `f` 对 `v` 是一条过原点的直线，斜率 `St/D = 4 Hz per (m/s)`。
整条线都画出来了，当前车速上有个点。

## 随机数是可复现的

涡的强度抖动和横向抖动全部来自 `mulberry32(0x5EED1E55)`，代码里没有一处 `Math.random()`。
同一个种子、同一组滑杆，导出两次的 PNG 逐字节相同。断言里有一条专门验这个：
同种子两次 `JSON.stringify` 必须相等，换个种子必须不等。

顺手也验了：抖动调到 0 时，涡心必须严格落在 `h(x)/2` 上（误差 < 1e-15）。

## 已知问题

1. **`St = 0.20` 是圆柱和二维平板的值，不是这辆车测出来的。** 方背车身的实测 St 在 0.18–0.30 之间，
   跟后窗倾角、离地间隙、尾部倒角都有关系。我把它当常数，意味着 `f` 的绝对误差可能到 ±30%。
   也就是说"67.6 Hz"这个数，说白了是"0.2 乘出来的 67.6"，不是量出来的。

2. **用车宽 D 当特征长度，但我的车不是矩形。** 真实车身的分离点随偏航角、侧风、地面间隙在动，
   等效尾宽能有 ±25% 的变化。图上那条 `λ = 0.250 m` 的橙线，精度大概只到 ±0.06 m。

3. **这张图是理想化的街，真车后面没有它。** 二维平行剪切层才会长出干净的两列交替涡。
   三维车身后面是发夹涡、纵涡、轮腔尾流混在一起，拿烟线看是一团乱麻。
   我画的"两列严格交替"是一个模型，不是照片。

4. **共用内核 `sheddingFreq()` 原来用错了特征长度，已经改了。** 它拿车长 L 算，
   得到 16.9 Hz，比按车宽算的 67.6 Hz 小 4 倍。我先写了个断言盯住这个 4 倍差，
   想等确认别的项目没依赖那个数再动——确认完了：`coast-decel`、`friction-loop`、
   `wake-drafting` 都只是带着这份文件的副本，没有任何一处调用它。

   现在内核改成按 `p.width = 0.050` 算，和这里完全一致（断言 14），
   旧的按车长算法挪进 `sheddingFreqByLen()` 只做对照（断言 14b 证明差别只来自
   特征长度）。**这条不再是已知问题，是一条已经关掉的账。**

5. **包络用直线，真实尾流是自相似的。** `h(x) = 0.028 + 0.32x` 是线性张开，
   实际钝体尾流宽度按 `x^(1/2)` 到 `x^(1/3)` 长。在 2.4 m 这个视窗里，直线和 `x^(1/2)`
   在末端差不到 8%，看不太出来；但要是把视窗拉到 10 m，线性会张开到 3.2 m，
   真实值大概只有 1.5 m，那就明显错了。

6. **涡核扩散系数用错了。** `r = √(4νx/u_c)` 是层流扩散解。`Re_D = 6.6×10⁴` 已经是湍流尾流，
   涡核靠的是湍流涡黏性 `ν_t`，通常比 `ν` 大两个量级。所以"低速核胖"这个效应我画出来了，
   但幅度被低估了大概 10 倍。图上 3.18 mm 对 5.85 mm 的对比，真实情况应该夸张得多。

7. **抖动幅度 0.18 是调出来好看的。** 它不影响涡数、间距、频率——只改强度和横向位置。
   我没有任何实测数据说它该是 0.18，只能说"看起来像那么回事"。

8. **视窗外的涡直接消失。** 我只生成 2.4 m 内的 21 个涡，出了左边界的就没有了，
   没有按强度衰减淡出的过程。真实尾流在 2.4 m 处还有很强的涡，只是被网格和噪声吃掉了。

9. **没画车轮尾流和地面效应。** 真车下面四个轮子会甩出四道尾流，地面还会把涡压扁。
   图里只有一个光秃秃的车身，这是简化得最狠的一处。

10. **温度只改了 ν，没改 ρ 和 St。** 20 °C 到 35 °C，`ν` 从 1.516e-5 涨到 1.65e-5，
    `Re` 掉 8%。但 `St` 在这个区间几乎不动，所以图上一点看不出来——这不算 bug，
    只是提醒一句：别以为拖温度滑杆会有反应，我没有温度滑杆。
