# result-archive —— 成绩档案

把队里 12 站成绩排成一张 1080×1920 的计时表，能搜、能按日期/用时/名次排，下面带一条用时趋势折线。

数据写死在 `src/results.js` 里。页面不读外部文件、不联网、不存东西。

---

## 怎么跑

```
node build.mjs
node tests/gate.mjs
node tests/visual.mjs
node tests/fonts.mjs
node tests/ascii.mjs
node tests/shot.mjs
```

换数据：编辑 `src/results.js`，重新 `node build.mjs`。

---

## 卡片长什么样

- 0–240 是 IG 状态栏死区，只放一条细线和 5.5% 透明度的 `ARCHIVE` 水印
- 240 起：橙色短杠 + `STEM RACING` + 66px「成绩档案」，右上角 68px 是总站数
- 412–486 三列：赛季 / 车型 / 排序
- 508 一行表头：赛事、日期、车、用时、名次
- 524 起是成绩表。冠军站左侧有一根橙色短杠，名次也是橙色
- 1012 起是用时趋势：竖网格 + 淡橙面积 + 橙色折线，最后一站实心点并标数值
- 1232 起是汇总：最快 / 平均 / 第一名站数
- 1394 起是页脚

行高跟着条数走，`rowLayout(n)` 在 62px 和 56px 之间取，一屏最多 8 行。

## 折线为什么要单独算

表格是被筛选和排序改过的，折线**不能跟着表格的排序走**——按名次排的时候如果折线也跟着重排，日期就乱了，趋势就没意义了。

所以 `drawChart()` 里重新按日期升序排了一遍，从左到右永远是时间顺序。

但折线**跟着筛选走**：搜「省赛」的时候折线只剩那两站。这是有意的（想看单条赛道的走势），但很容易被误读成「成绩变少了」，见下面缺陷 2。

面积填充用的是 `rgba(232,89,12,0.14)` 不是 0.10。0.10 叠在 `#0b0b0c` 上算出来的亮度是 21.3，低于 24 的墨量阈值，等于在白画——第一版就是这么写的，墨量只从 24.49% 涨到 24.56%，等于没加。

## 门禁在查什么

通用部分在 `tests/core.mjs`：产物静态扫描 7 条禁用 API、运行时插桩 5 个计数器必须全 0、导出 PNG 魔数 + 字节数、页面无外站资源、全程无外网请求、两张截图。

`tests/gate.mjs` 是本项目自己的：

| # | 断言 |
|---|---|
| 1 | 默认 12 站全显示，排序是日期，画布 1080×1920 |
| 2 | 三种排序各自满足自己的单调性；名次排序第一条必须是第 1 名；最快必须是 1.042 s；三种排序不能完全相同（否则说明 setSort 没接线） |
| 3 | 搜「省赛」出 2 条，且结果里不能混进别的赛事 |
| 4 | 搜车号 07 出 7 条 |
| 5 | 搜不存在的东西 → 0 条，卡面墨量 ≥ 8% |
| 6 | 重置回 12 条 |
| 7 | 刷新后回到 12 条、搜索框空、排序回日期 |

第 2 条一开始写错了：原本想用「按日期排和按用时排的第一条不能相同」来证明两种排序都生效。但队里用时一直在进步，按日期和按用时排出来本来就几乎一样，这条断言会误报。改成验各自的单调性，再单独加一条「三种排序不能全等」。

## 已知缺陷

1. **12 站只画 8 行。** 一屏最多 8 行（行高最低 56px，再压手机上就看不清了）。剩下 4 站不在表上，只在折线里。汇总区写了「显示 8 / 12」，但发到手机上不一定有人注意。

2. **折线跟着筛选走。** 搜「省赛」的时候折线只剩 2 个点，看起来像成绩断崖。应该有个开关让人选「折线跟筛选 / 折线永远全量」，没做。

3. **日期只显示 mm/dd。** 表格里 `2025-09-20` 显示成 `09/20`，跨年的时候 2025 和 2026 的 09 月长得一样。表头没有年份，只能靠赛季那格 `2025 → 2026` 猜。

4. **纵轴没有刻度。** 折线只标了「1.042 – 1.318 s」这个范围和最后一站的数值，中间那些点读不出具体时间，只能看相对高低。加刻度会让 140px 高的折线区更挤，就没加。

5. **用时当成精确值。** 三位小数直接 `toFixed(3)` 打到卡上，没有 ±、没有重复测量的均值和标准差。真实计时会有抖动，这里画出来的是一条丝滑的曲线，比实际好看。

6. **12 站数据是我编的。** 量级是按队内记录估的（1.04–1.32 s / 20 m），不是实测。发之前得换成真的记录表。

7. **4:5 封面切掉眉标。** 封面居中裁切，取源图 y 285–1635，y=240 的橙色短杠和 y=276 的 `STEM RACING` 不在封面里。

8. **导出文件名不带状态。** 三种排序、任意搜索结果导出来都叫 `result-archive-1080x1920.png`，连导两次浏览器会加 `(1)`，事后分不清哪张是哪张。

9. **没有导出 CSV。** 想把表拿回 Excel 对一遍做不到，只能看图。加一个 `toCSV()` 是十几行的事，但这轮没做。
