# 装车台 · build-a-car

> 在线版：https://zhuka4141-cmyk.github.io/stem-racing/projects/build-a-car/
一个能玩的选件器。四组零件各三选一，3⁴ = 81 种装法，每换一个零件，
质量、质心、迎风面积、20 m 成绩、三条限值全部重算。

做它的起因很蠢：队里换了三次装法，每次成绩变了都要有人手算一遍是不是
超限，算到第四次就算错了。所以干脆把算式做成能点的那种。

## 怎么开

双击 `index.html`。不用起服务器，不用装东西。

导出的按钮在右边，出两张：1080×1920 竖版和 1080×1350 封面。
下载下来直接能发。

## 里面有什么

左边是侧视图，会跟着你选的零件变——车壳长短、迎角、轮径、配重块位置、
尾翼角度全都是实时画的，不是贴图。

右边四排按钮：

| 组 | 三个选项 | 单个质量 |
|---|---|---|
| 车身 | 标准壳 / 短鼻 / 长尾低阻 | 20.12 / 19.20 / 21.40 g |
| 车轮 ×4 | 轻量 26 / 标准 30 / 宽体 34 | 2.79 / 3.72 / 4.78 g |
| 配重 | 轻 16 g 前左 / 标 30 g 中置 / 重 36 g 后右 | 16 / 30 / 36 g |
| 尾翼 | 无 / 低阻 4° / 大尾翼 9° | 0 / 1.6 / 3.2 g |

全组合扫下来整车质量从 46.4 g 到 79.7 g，20 m 成绩从 0.911 s 到 1.514 s。
这两个端点都是真的跑出来的数，不是估的。

## 三条限值

改一个零件，这三条会重新判一遍，超了左边那条竖线变红。

**1. 质心横向偏移 ≤ 0.568 mm**

**2. 前轮抗偏航力矩 ≤ 5.96 mN·m**

**3. 等效惯性质量比 ≤ 1.32（基准 1.229）**

第 2 条是队里台架量的数，是真正有出处的那个。第 1 条是从它反推的：

```
0.568 mm = 5.96e-3 N·m ÷ (21 N × 0.5)
```

0.5 是参考质心站位上前轴分担的比例（质心到后轴 0.070 m ÷ 轴距 0.140 m）。

81 种装法里，偏移超限的有 54 种，力矩超限的 54 种，惯性比超限的 9 种。
**三条都真的够得着**，不是画在那里永远亮不了的红线——这点我专门写了断言。

## 一个我自己埋的坑

第 1 条原来写死成 **1.32 mm**，注释还写着「this lands near 4 mN·m,
i.e. just inside 5.96」——描述的是一大截余量。

代进去算：`21 × 1.32e-3 × 0.5 = 13.86 mN·m`，是上限的 **2.3 倍**。
不是「刚好在下面」，是稳超。那段注释在骗人。

顺着查下去：`5.96e-3 ÷ 1.32e-3 = 4.52 N`。**4.52 N 是旧的推力值**。
这对数字是在 4.5 N 平台推力下算出来的，后来推力改成 21 N，
力矩上限跟着改了，偏移上限没改，注释也没改。

现在两边都从 `M_YAW_LIMIT` 反推，`parts.js` 不再自己写一份常数。
门禁里专门有一条断言盯着这个：偏移上限必须等于 `5.96e-3 / (21 × 0.5)`，
且不能等于 1.32 mm。

## 已知问题

这一节是给自己看的，不是免责声明。

1. **第 3 条限值 1.32 是我自己定的。** 队长只说了「偏离基准太多」，
   没给数。基准 1.229 有出处（队里标定车 79.88 g / 65 g），上限没有。
   它现在会触发 9 种装法，所以它是有约束力的——但约束力来自我编的数。

2. **迎角对阻力的系数 0.045/deg 和尾翼 0.038/deg 是拍的。** 没做过风洞，
   也没有 CFD 对照。这两个数直接决定了「长尾低阻」到底比「标准壳」快多少。

3. **滚阻 0.008、轮惯量系数 1.0 同样是拍的。** 后者假定轮子是完全实心的
   圆柱绕轴转，实际是轮毂加一圈胎面，转动惯量会小一些。

4. **完全不考虑打滑。** 21 N 峰值推力作用在 65 g 的车上，起步瞬间
   轮子需要提供的切向摩擦系数远超 0.6，物理上必然打滑。模型里 t=0 那一段
   的加速度是假的。

5. **不考虑跑偏。** 质心横向偏 4 mm 时车会真的往一边走，会蹭导轨，
   会损失速度。这里只把它变成一个「超没超」的红线，不计入成绩。

6. **质心按零件质量加权算，但没算胶水、螺丝、线束。** 那些东西
   实际有 2–4 g，且不在质心。

7. **成绩公式只算直线。** 20 m 是标称距离，没有起跑反应时间，
   也没有导轨长度误差。

8. **侧视图的配重位置是放大画的。** 真实配重贴在底盘上，正视图根本看不见，
   侧视图里我把它画在车身上方，纯示意。

## 目录

```
build-a-car/
├── index.html            双击可开
├── src/
│   ├── physics.js        推力、阻力、积分；三条限值的定义在这里
│   ├── parts.js          零件库 + 整车实时计算
│   ├── car.js            侧视图绘制
│   ├── main.js           版面和对外钩子
│   └── reel-export.js    导出（构建时从 shared/ 拷进来）
├── dist/app.js           构建产物，IIFE，file:// 能直接跑
├── tests/gate.mjs        门禁
└── build.mjs             esbuild 打包
```

改完源码要重打包：

```
node build.mjs
node tests/gate.mjs
```

## 门禁在验什么

```
GATE OK  |  竖版 180KB  封面 161KB  |  墨量 9.72%  133 色  |  81 组合
```

- selfTest 全过
- 偏移上限 = 5.96e-3 / (21 × 0.5)，且 ≠ 1.32 mm
- 81 种装法成绩全在 0.9–1.6 s 内，且最重的比最轻的慢
- 三条限值各自至少触发过一次
- **换配重后导出的字节哈希必须变**（空壳也能导出合法 PNG，字节数证明不了任何事）
- 安全区墨量 ≥ 8%、色彩 ≥ 48 种（量像素）
- 安全区内最长空白带 ≤ 150 px
- 无 console / pageerror

最后那两条是以前吃过亏才加的。之前有个项目 `main.js` 只有 1 KB，
`selfTest` 返回 true、导出 67 KB 的 PNG，门禁一路绿——因为门禁只看了字节数。
现在的门禁会对比两个参数状态下的导出哈希，一样就判失败。
