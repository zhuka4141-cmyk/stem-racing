# 加速曲线分解 · Accel Curve Lab

> 在线版：https://zhuka4141-cmyk.github.io/stem-racing/projects/accel-curve-lab/
把 20 米加速过程拆开看：推力、气动阻力、滚动阻力、净加速度，外加一条叠在右轴上的速度曲线。

这是车队内容计划的第 02 期。纯静态网页，双击 `index.html` 就能开，不联网，不上传任何数据。

---

## 为什么做这个

之前给队里讲「为什么后段加速没劲」，全靠嘴说。讲完大家点头，转头还是不明白。

后来把三条力画在同一张图上，一眼就看出来了：推力只在前一百多毫秒存在，之后整段路程只有阻力在咬。观众不需要听懂公式，看图就够。

## 模型

二十米直线，CO₂ 一次性爆发，之后全程滑行。

### 运动方程

```
(m + Σ I_w / r_w²) · a = F_thrust(t) − ½ρ·Cd0·A·v² − Crr·m·g
```

左边是等效惯性质量——平动质量加上四个轮子的转动惯量折算。轮子会被带着转起来，这部分惯量不能漏。

```js
// src/main.js
export function effMass(p = P) {
  return p.mass + (p.wheels * p.wheelI) / (p.wheelR * p.wheelR);
}
```

默认参数下：65 g 平动 + 14.9 g 折算 = **79.9 g 等效惯性质量**。
也就是说，同样 21 N 的推力，加速效果比按 65 g 算要弱 19%。

### 推力曲线

半正弦爆发，烧完即零：

```
F_thrust(t) = F_peak · sin(π·t / t_burn)    t < t_burn
            = 0                              t ≥ t_burn
```

### 阻力

```
F_drag = ½ · 1.204 · Cd0 · A · v²
F_roll = Crr · m · g
```

### 积分

定步长欧拉法，`dt = 1e-4 s`。跑到位移 ≥ 20.00 m 为止。

## 一个必须写下来的发现

车队另一条建模路线给出的参考值是 **1.230 s 完赛、19.93 m/s 末速**。

这两条**互相矛盾**。

20 米跑 1.230 秒，平均速度必然是 `20 / 1.230 = 16.26 m/s`。
而声称的末速是 19.93 m/s，比平均速度快了 23%。

CO₂ 推力只持续几十到一百多毫秒，之后全程受阻力减速。所以末速度一定**低于**峰值速度，而峰值速度出现在推力结束那一刻。
既然末速高于全程平均速度，就意味着车在到达终点时还在加速——这在推力早就烧完的前提下不成立。

我在整个参数平面上扫过一遍（F_peak 从 20 N 到 46 N，t_burn 从 30 ms 到 120 ms），
**没有任何一组参数能同时命中 1.230 s 和 19.93 m/s**。最接近的一组是 23 N / 115 ms，给出 1.047 s / 19.38 m/s。

所以本项目没有采用那组参考值，而是选了自洽的 21 N / 110 ms → 1.188 s / 16.91 m/s。
两个数都落在合理区间内，且互相不矛盾。

如果车队实测出来确实是 1.23 s、末速接近 20 m/s，那说明模型缺了东西——
最可能是推力持续时间比 110 ms 长得多，或者质量比 65 g 小。到时候改参数重跑就行。

## 已知问题

这些是真的没做好的地方，不是客套话。

1. **滚动阻力写成了常数。** 真实滚动阻力随法向载荷变化，而加速时载荷会向后轴转移。现在 `F_roll = Crr·m·g` 全程不变，等于默认四轮载荷恒定。对 20 米这种短程影响不大，但模型上是不对的。

2. **完全没有轮轨侧向力（scrub）项。** 支配方程里的 `F_scrub` 被整个省掉了。这意味着这个模型假设车是一条完美的直线、四轮零滑移。一旦车真的跑偏，实际成绩会比这里算的差，而模型不会告诉你差多少。

3. **推力曲线是猜的。** 半正弦形状没有任何实测依据，纯粹是因为它比矩形波好看且物理上更合理一点。真实的 CO₂ 气瓶推力曲线会有一个尖锐的初始峰值然后快速衰减，形状和半正弦差别不小。这一条直接影响所有绝对数值的可信度。

4. **Cd0 是常数。** 真实阻力系数随雷诺数和姿态角变化。20 米全程速度从 0 到 17 m/s，雷诺数变化接近一个数量级，Cd0 不可能纹丝不动。

5. **欧拉积分，不是 RK4。** 定步长 1e-4 秒下误差应该很小，但我没有做步长收敛性验证，所以「很小」这个说法本身没有证据。想看的话把 `dt` 调成 1e-5 对比一下结果。

6. **没有抬头力矩和升力。** 车头可能会被气流抬起来，这会改变接地法向力，进而改变滚阻和牵引极限。模型里完全没有这一层。

7. **界面上的合理性区间是我定的。** 1.000–1.250 s 这个范围来自我对 F1 in Schools 各级别成绩的印象，没有查证过具体规则文档。如果你有官方成绩分布，应该用那个替换。

## 操作

- 四个滑块实时重算整条曲线：质量、Cd0、推力峰值、推力时长
- 四个开关单独隐藏某条曲线，方便一条条讲
- 暂停按钮停住时间游标
- 导出按钮一次出两张：1080×1920 竖版 + 1080×1350 封面（IG 资料页用 4:5 裁切）
