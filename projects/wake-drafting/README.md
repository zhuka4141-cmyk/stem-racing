# wake-drafting · 尾流跟车

> 在线版：https://zhuka4141-cmyk.github.io/stem-racing/projects/wake-drafting/
一句话：前车拖出的低速区同时压低动压和阻力系数，这张图把这两件事的乘积画出来。

## 为什么做这个

教练在讲评的时候说了一句"跟车能省阻力"，全场点头，没人算过到底省多少。
我们回去第一件事就是算，算完发现是 **0.15 %**，然后就决定把这张图做出来——
不是因为它证明跟车有用，是因为它证明跟车没用。

比赛里这件事根本不可能发生：CO₂ 组是单车单轨发射，两条车道隔着一米。
所以这个模型从头到尾是一个**反事实推演**，图上画的是一辆不存在的车。
我把这句话先在 README 里写清楚，免得别人看图以为我们在建议跟车。

## 这块的物理

尾车吃到的阻力是两个因子相乘：

    F_drag(g) = q(g) · C_d(g) · A
    q(g)/q∞  = 1 − 0.22·e^(−g/0.85)
    C_d(g)/C_d0 = 1 − 0.38·e^(−g/1.15)

g 是跟前车尾端的距离，单位车长 L = 0.200 m。

数值（v = 16.906 m/s，整跑末速）：

    q∞ = ½ρv² = ½ × 1.204 × 16.906² = 172.0 Pa
    前车阻力 = 172.0 × 0.34 × 1.6×10⁻³ = 93.6 mN
    g = 0   ：93.6 × 0.78 × 0.62 = 45.3 mN（−51.6 %）
    g = 0.5 ：93.6 × 0.878 × 0.753 = 61.9 mN（−33.9 %）
    g = 1   ：93.6 × 0.932 × 0.841 = 73.4 mN（−21.6 %）
    g = 2   ：93.6 × 0.980 × 0.934 = 85.6 mN（−8.5 %）
    g = 5   ：93.6 × 0.999 × 0.995 = 93.1 mN（−0.6 %）

所以"贴上去"省 48 mN，"隔一个车身"就只剩 20 mN。
而峰值推力是 21 N = 21000 mN，最理想情况省下的也是 **0.15 %**。

## 速度场为什么和阻力模型对得上

俯视速度场用的是同一套参数，不是另配的一组好看的数字：

    u/U(x,y) = 1 − Au·e^(−x/0.85)·e^(−y²/2σ(x)²)
    σ(x) = 0.50 + 0.21x

Au 是被反解出来的：要求中线上的 (1−Au)² 正好等于 0.78，于是

    Au = 1 − √(1 − 0.22) = 0.1167

这条约束写进了断言。如果哪天有人改了 0.22 却没改 Au，门禁会红。

俯视图上那三条向左凸出的曲线是**横向速度剖面**，凸出长度正比于该处的速度赤字；
另外三对细线是 u/U = 0.99 / 0.97 / 0.95 的等值线，是直接解析解出 y 来画的：

    d = Au·e^(−x/τ)·e^(−y²/2σ²) = 目标赤字  ⇒  y = σ·√(2·ln(amp/目标))

## 已知缺陷

1. **比赛里不可能发生。** CO₂ 组单车发射，没有前车。整个项目是反事实推演，
   图上那辆"前车"在现实中不存在。这是最该先知道的一条。

2. **四个尾流系数全是拍出来的。** 0.22、0.38、0.85、1.15 没有一个来自实测或文献，
   只是"看起来像指数衰减"的合理形状。改任何一个，下面所有结论都跟着变。

3. **近场赤字差了一个量级。** 真实钝体在 0.2 个车长处的速度赤字有 40–60 %，还有回流区。
   这个高斯模型最大只有 11.7 %，所以 g < 0.3 L 的数全部不能当真——
   而偏偏 g = 0 那一栏是图上最显眼的数（−51.6 %）。

4. **准静态假设在加速段不成立。** 模型假设尾流瞬间建立，但车在以 21 N 加速。
   半个车身的对流延迟是 0.2×0.5/16.9 = 5.9 ms，和 110 ms 的推力脉冲同一量级，
   不能说"稳态"。图上所有值都是末速处的瞬时值，不是整跑积分。

5. **横向对齐要求高得离谱。** 赤字在横向是 σ₀ = 0.5 L = 100 mm 的高斯，
   偏 100 mm 赤字掉到 e^(−0.5) = 61 %。要吃到九成收益得对齐到 ±30 mm 以内，
   手工装车做不到。

6. **车长雷诺数掩盖了真正的尾流源。** 2.23×10⁵ 这个数是按 0.2 m 车身算的，
   但真实的尾流是车轮和导轨销拖出来的。导轨销直径 3 mm 处的 Re 只有 3.3×10³，
   完全不是一个流态。模型把这件事抹平了。

7. **Cd 折减率 0.38 没有依据支撑。** 动压赤字和阻力系数折减是两个不同的机制
   （一个是速度亏损，一个是压强场变化），我让它们同量级纯属好看。
   没有任何理由说它们必须一个数量级。

8. **没有地面效应。** 车底距轨面约 1 mm，地面边界层会压扁尾流、抑制展向扩散，
   模型里完全没有这一项。

## 自检

`tests/gate.mjs` 调 `window.__app.selfTest()`，13 条断言，重点几条：

- 中线 (1−Au)² 必须等于 q/g=0 的动压比，误差 < 1e−12
- 阻力比在 201 个采样点上严格单调递增
- g = 0 时阻力比等于 0.78 × 0.62
- g → ∞ 时回到 1，误差 < 1e−6
- 前车阻力与间距无关（这条防的是把前车也写进尾流）
- 省下的力非负且永远小于前车阻力
- 跟车收益不足峰值推力的 1 %（这条是结论，不是约束，挂掉说明参数被改坏了）
- 画布几何：速度场不出安全区、最大间距时尾车仍在框内
