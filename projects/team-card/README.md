# 车队交易卡生成器

STEM Racing（原 F1 in Schools）用的车队卡。左边填表，右边实时出卡，导出 PNG 直接发 Instagram。

双击 `index.html` 就跑。不用装依赖，不用起服务器，断网也一样。

## 为什么是纯 SVG

之前试过一版用 canvas 逐帧画的，改一个字号要把所有换行重算一遍，两小时全花在对齐上。

现在 `src/card.js` 里 `front(st)` 从头到尾就是 `g += ...`，想看哪一层直接搜那一行。整站 `src/` 三个文件加起来 30 KB 出头。

导出是三步：SVG 字符串塞进 `div.innerHTML`、`XMLSerializer` 序列化、丢给 `<img>` 再 `drawImage` 到 canvas，`toBlob('image/png')` 出字节。没用 html2canvas 之类的库，因为我要控制的就是这几步，多一层包装反而不好查。

## 字体为什么要塞成 base64

`file://` 下字体的 origin 是 `null`，普通字体文件会被 CORS 拦掉。页面会安静地掉回系统字体，导出的 PNG 里数字就不是等宽的。

所以 `assets/fonts-data.js` 把四个 woff2 编成了 data URI，在页面 CSS 和导出的 SVG 里各挂一次。导出时必须挂进 SVG。`<style>` 是页面级的，跟着 SVG 变成图片之后就不生效了。

等宽数字是硬要求。`54.2` 和 `1.087` 右对齐才对得上小数点，字体一换这个就散了。

字号只在四档里跳：96（队名，塞不下会自己降到 38）、72（参数值）、24（单位）、13 和 11（标注）。中间不取别的值。

## 两条尺寸

- **1080 × 1350（4:5）** 信息流用，占满版面不会被裁
- **1080 × 1920（9:16）** Story 用。中间那 1350 px 和 4:5 版逐像素对齐，上下各 285 px 放编号和标尺

9:16 不是把卡片拉长，是把 4:5 原样嵌进去。标尺量的是这个画框本身，不承载信息。

## 设计上守的几条

- 圆角一律 0。`border-radius: 0` 在 CSS 里写了 5 次，是声明不是漏改
- 只有一个强调色，三选一：卡钳红 `#E2231A` / 计时绿 `#16D97F` / 测绘橙 `#E8590C`。都是赛车现场真有的颜色
- 深色底上 13 px 的字不用 `#E2231A`（对比度只有 4.17），用提亮一档的 `#F2453A`（5.3）。纸色带上反过来，用深灰 `#4A4A50`（7.8）
- 参数条和页脚条是矩形色带，不是浮起来的胶囊
- 装饰只出现在四个角上：定位角标、图纸编号、右上角的 `No. 07 / 12`

## 测试

```
node tests/gate.mjs
```

起本地 Chromium 打开 `file://`，DNS 全部指向 `~NOTFOUND`，然后断言：

- 没有 console.error、没有 pageerror、没有 4xx、没有跨域请求
- `document.fonts.check` 两个字体族都在（证明 woff2 没被 CORS 拦）
- 改输入框会重绘，且不是整页刷新
- 两个尺寸导出的确是 PNG（文件头 `89 50 4E 47`）、都大于 50 KB、宽高精确到像素
- 队徽真的被光栅化进去了：在 (884,268) 取色，期望洋红
- 9:16 的标尺线和刻度真的画出来了（取 (600,1732) 和 (56,1740) 的亮度，和背景比）

截图和导出件落在 `qa/`。

另外两个不是给 CI 用的，是我调布局时用的：

- `node tests/audit.mjs` 把每个 `<text>` 的 bbox 打出来，标出越界和两两重叠
- `node tests/ascii.mjs 4:5` 把导出的 PNG 压成 30 px 一格的字符密度图
- `node tests/inspect.mjs` 数每个色带用了多少像素、哪些颜色真的出现了，并对比开/关 webfont 的字宽差

这台机器上没有视觉模型，我只能靠这两个看构图。密度图里 360–500 那一整片空的就是这么发现的。队徽板原来只有描边没有填充，整块漏了。

## 已知问题

1. `assets/fonts-data.js` 有 112 KB，全是 base64。首屏要多解析一次，慢几十毫秒。
2. 刷新之后队徽没了。图片只在内存里，没写 IndexedDB。这是故意的。写进本地存储意味着别人的队徽文件会留在我的项目目录或者缓存里。
3. 中文队名会掉到微软雅黑。Barlow Condensed 没有中文字形，中英文的字宽完全不是一套，自动缩号会缩得比较狠，96 px 的标题遇到六个字的队名可能掉到 50 左右。
4. 9:16 的上下两条装饰在 IG Story 里会被头像和回复框压掉一部分。那两条不承载信息，但发之前还是拿手机看一眼。
5. 导出固定 1×，没有 2×。1080 宽发 IG 够了，打印不够。
6. 首屏可能闪一下 fallback 字体，要等 `document.fonts.ready` 才稳。
7. 只在 Chromium 里跑过 gate。Safari 和 Firefox 没测，不确定 `toBlob` 和 SVG 内嵌 data URI 字体在那边表现一样。
8. 字体子集只有拉丁（U+0000-00FF 加 U+2000-206F）。`°` `Ø` `×` `²` `·` 都能用，`№` 不行，所以编号写成 `No.` 而不是 `№` 的原因。
