# 轮轨接触受力 · Wheel Contact

> 在线版：https://zhuka4141-cmyk.github.io/stem-racing/projects/wheel-contact-3d/
车在导轨上跑的时候，左前轮接地点上到底有几个力、各多大、什么时候扛不住。

做成三维是因为平面图讲不清方向：法向力朝上、切向摩擦朝后、侧向力朝侧面，三个矢量互不正交于纸面，只有转起来才看得懂。

---

## 怎么跑

双击 `index.html`。改代码后：

```
node build.mjs
```

`file://` 下 ES module 被 CORS 拦，所以 esbuild 打 IIFE。

## 门禁

```
node tests/gate.mjs
```

它做三件事，缺一不可：

1. **逻辑对** —— `selfTest()` 加九条物理断言
2. **画面有内容** —— 直接量像素：安全区墨量 ≥8%、色彩 ≥48 种
3. **画面随参数变** —— 改偏移后两次导出的哈希必须不同

第 3 条是专门防「假绿」的。空壳也能导出 300KB 的合法 PNG，也能让 `selfTest()` 返回 true，但改参数画面不会变。这个项目一开始就是 2660 字节的空壳，带着 `GATE OK 67KB / 13.38% / 60 色` 骗过一次。

## 三个力怎么来的

```
轴荷      N_f = m·g·(1 − comFrac) + F·dh / L_wb         dh = 0
          N_r = m·g − N_f
偏航上限  M_lim = μ · N_f · armPin
偏航需求  M = F_peak · d                                 d = 横向偏移
侧向需求  F_lat = M / armPin
临界偏移  d_crit = M_lim / F_peak
```

代入本模型参数：

```
m·g        = 0.065 × 9.81        = 0.6377 N
N_f        = 0.6377 × 0.45       = 0.2870 N
M_lim      = 0.60 × 0.2870 × 0.0375 = 6.456 mN·m
d_crit     = 0.006456 / 21.0     = 0.3074 mm
```

还有一个恒等式，`selfTest()` 第 3、7 条就是验它：

```
M / M_lim = d / d_crit
```

所以「超限多少倍」= 「偏移是临界值的多少倍」。4.00 mm 就是 13.0 倍。

---

## 为什么不是 1.32 mm

网上和旧文档里流传的「临界偏移 1.32 mm / 前轮抗偏航上限 5.96 mN·m」，**这对数字属于旧模型**，本模型没有采用。

验一下就知道它对应哪个推力：

```
5.96 mN·m ÷ 1.32 mm = 4.52 N
```

4.52 N 正是被废弃的「4.5 N 平台推力」模型。`shared/racing-core.js` 开头写明了废弃原因：那组数是为了硬凑 1.230 s / 19.93 m/s 标定出来的，而那两个数自身矛盾（20 m 跑 1.230 s 平均只有 16.26 m/s，CO₂ 推力只持续一百多毫秒，之后全程减速，末速不可能到 19.93）。

换成自洽的 F_peak = 21 N，临界偏移就是 **0.307 mm**。

这两个数不能混用。混用会得到「4 mm 偏移才超限 3 倍」这种结论，而真实情况是 **13 倍**——差了四倍，工程判断会完全反过来。

## 参数表

| 参数 | 值 | 标注 | 说明 |
|---|---|---|---|
| 整车质量 m | 0.065 kg | **VERIFY** | 没上秤 |
| 轮轨摩擦系数 μ | 0.60 | **TYPICAL** | 文献值，没测过 |
| 导轨销到前轴 armPin | 0.0375 m | **TYPICAL** | 按整车几何估的 |
| 轴距 L_wb | 0.130 m | **TYPICAL** | 同上 |
| 质心距前轴 / 轴距 | 0.55 | **TYPICAL** | 意味着 45% 重量在前轴 |
| 推力峰值 F_peak | 21.0 N | **VERIFY** | 气瓶压力、破膜时间、喷管面积都没实测 |
| 燃烧时长 t_burn | 0.110 s | **VERIFY** | 同上 |
| 重力加速度 g | 9.81 m/s² | FIXED | |

`[VERIFY]` 的意思是这个数一旦实测变了，结论就要重算——尤其是 μ 和 armPin，临界偏移对这两个是线性的。

## 已知问题

**1. 4:5 封面只看得见源图 y 285..1635，两头各切 285 px。**
这一条之前记错了，我按「上对齐裁到 1350」写的，说结论行（y=1430）会被切掉。不对。`shared/reel-export.js` 的 `resample()` 是**居中裁切**：`scale = max(1080/1080, 1350/1920) = 1`，`dh = 1920`，`dy = (1350 − 1920)/2 = −285`。所以可见窗口是 285..1635，结论行 1408..1434 映射到封面 1123..1149，一直在画面里。

真正被切掉的是页眉那根 3 px 强调条——原来画在 y=282，占 282..285，封面从 285 起，整根都看不到。已经挪到 292。现在 `window.__app.getBands()` 会把每一次 `fillText` / `fillRect` 的真实包围盒记下来，门禁量这 25 个盒子，要求全部落在 285..1635 内，并且单独断言判决行在窗口里。把强调条挪回 282 会红。

**2. 横向偏移在画面上放大了 40 倍。**
真实 0.4 mm 在 200 mm 长的车上根本看不见，所以 `carGroup.position.z = −(offset/1000) × 40`。画面上标了「已放大 40 倍」，但这个数字本身没有物理意义，不能拿来量。

**3. 侧向力箭头会被截断。**
箭头长度以整车重力为 1 个单位，超过 1.0 就截断并变红。4 mm 时侧向需求是 2.24 N，而整车重力只有 0.638 N——早就超过 3.5 个单位了，画出来永远是同一个长度的红箭头。**真实的倍率只能看数字，不能看箭头。**

**4. 只分析了左前轮。**
另外三个轮子完全没画。后轮在急加速时会不会离地、右前轮载荷怎么变，这里都没算。真实情况四个轮子互相耦合。

**5. 恒定摩擦假设。**
用的是库仑摩擦 `μ·N`，假设摩擦力到上限就恒定不变。真实轮胎有滑移曲线，接近极限时摩擦会先升后降，`μ` 不是常数。

**6. 完全静态，没有时间积分。**
这是「某个瞬间的受力快照」，不是一段过程。推力从 0 升到 21 N 再到 0 的这一百多毫秒里，载荷转移是动态的，这里全被抹成一个稳态。

**7. dh 取 0 是个假设，而且这个假设很脆。**
`dh` 是推力线相对质心的高度差。取 0 意味着两者同高——没人测过。而且这个项的量级很吓人：

```
dh = +4 mm 时，F·dh/L_wb = 21 × 0.004 / 0.130 = 0.646 N
```

整车重力才 0.638 N。也就是说**推力线只要高出质心 4 毫米，前轴载荷就翻倍到超过整车重**，后轮直接离地、车头扎下去。这不是模型 bug，是真实约束——但界面上没有任何提示，因为它藏在 `dh = 0` 这个默认值里。

**8. 质心前后位置没做成可调。**
`comFrac = 0.55` 写死了。但它直接决定 `N_f`，也就直接决定临界偏移。想试「把电池往前挪 10 mm 会怎样」，现在只能改代码。

**9. 临界偏移只有 0.307 mm，滑块 0–8 mm 的量程几乎全是超限区。**
八个毫米里有 7.7 mm 都是红的，视觉上分不出 0.5 mm 和 8 mm 的差别（都是红的）。量程应该改成 0–1.5 mm 才看得清过渡，但按规格要求保留 0–8。

**10. `ctx.letterSpacing` 只有 Chromium 认。**
Firefox 和 Safari 直接忽略，字距会变。只在 Chromium 里验过。

**11. 三维场景里的地面是平的，导轨是一条直棱。**
真实导轨有凹槽、车轮有轮缘，接触不是点接触而是一小片。这里为了画得清简化成了点和线。

## 文件

```
wheel-contact-3d/
├─ index.html          滑块 + 复选框 + 画布
├─ build.mjs           esbuild 打 IIFE
├─ src/main.js         物理 + 三维场景 + 二维叠加
├─ src/reel-export.js  导出工具（构建时从 ../../shared 覆盖）
├─ design-tokens.css   配色（同上）
└─ tests/gate.mjs      门禁
```

`src/reel-export.js` 和 `design-tokens.css` 每次构建都会被 `../../shared/` 覆盖，**要改就改 shared 那份**。

物理公式内联在 `src/main.js` 里，没有 import `shared/racing-core.js`——因为 `build.mjs` 不会把它拷进项目目录。要改公式，两处都得改。
