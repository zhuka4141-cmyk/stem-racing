# 虚拟风洞 · 迎角与阻力

> 在线版：https://zhuka4141-cmyk.github.io/stem-racing/projects/wind-tunnel-3d/
一条 20 米的直线加速赛道，我们把迎角从 0° 拧到 8°，成绩掉了 0.09 秒。
这个页面就是拿来解释这 0.09 秒花在哪儿的。

浏览器打开 `index.html` 就能跑。不用服务器，不用联网。

## 屏幕上有什么

一个 200 mm 的 CO₂ 直线加速车模型，泡在一股虚拟气流里。

- 拖动「迎角 AOA」滑杆：车体俯仰跟着变，阻力和雷诺数实时重算
- 拖动「气流速度」滑杆：来流从 8 变到 30 m/s
- 「尾流」勾选框：关掉它，车后的速度亏损和湍流扰动就消失
- 「导出 9:16」：吐出两张图，一张 1080×1920 竖版，一张 1080×1350 的 4:5 封面

画面里的数字全部是算出来的，没有一个是写死的文案。

## 阻力怎么算的

```
Cd(θ) = Cd0 + 1.9 · sin²(θ)
Fd    = ½ ρ v² · Cd · A
Re    = v · L / ν
```

参数：

| 符号 | 值 | 状态 |
|---|---|---|
| ρ 空气密度 | 1.204 kg/m³ | 固定值，20 °C 海平面 |
| ν 运动粘度 | 1.516e-5 m²/s | 固定值，20 °C |
| L 车长 | 0.200 m | 规则书值，每次比赛前要重新确认 |
| A 迎风面积 | 1.6e-3 m² | **估的**，我们自己没实测过 |
| Cd0 零迎角阻力系数 | 0.34 | **估的** |

界面上那行小字 `ρ[FIXED] A[TYPICAL] CD0[TYPICAL] ν[FIXED]` 就是在标这个。
凡是标 TYPICAL 的，都是我们从同类钝体文献上取的中值，不是实测。

**这不是 CFD。** 它是工程近似：把车身当成一个带迎角的钝体，用经验公式叠一个 sin² 修正。
真正的 CFD 要网格、要边界层、要几小时算力，我们做不了，也没必要——我们要的是趋势对不对。

## 流场是怎么画的

用的是理想绕流的解析解，不是随便凑的向量场：

```
u = U(1 − R²(x² − z²)/r⁴)
w = −U(2R²xz)/r⁴
```

`R` 是等效阻塞半径，我们取 30 mm。尾流段另外叠了一个指数衰减的速度亏损和高斯分布的湍流扰动。

选解析解的原因是它便宜——2600 个粒子在 CPU 上逐帧积分，1080×1920 还能跑满帧。要是上真 CFD，这个页面就跑不动了。

## 怎么验证它没坏

```bash
node build.mjs        # 打包成 dist/app.js（IIFE，file:// 下能直接跑）
node tests/gate.mjs   # 门禁：无 console error、无外部请求、导出真实字节、物理断言
node tests/visual.mjs # 画质：安全区墨量、连续死区检测、色彩层次
node tests/ascii.mjs  # 把画面渲染成字符密度图，肉眼看布局
```

门禁会断言这几件事，任何一条挂了直接非零退出：

- 迎角 8° 的阻力必须大于 0°
- Re 必须落在 1e5 ~ 1e6 之间
- 导出的 PNG 必须大于 4 KB 且魔数正确
- 改参数后画面必须真的变了（防"滑杆是假的"）

`tests/ascii.mjs` 是这次做出来的副产品。因为我们这边没有能读图的模型，就把画布转成字符密度图看布局——意外地好用，比截图清爽。

## 为什么用 esbuild 打包

three.js 从 r160 起不再提供 UMD 构建，只有 ESM。而 ESM 在 `file://` 协议下会被 CORS 拦死。

试过三条路：起本地服务器（违背"双击就能开"）、手写 import map（一样被拦）、内联 ESM（`export` 语句在 inline module 里没法暴露到全局）。

最后选了 esbuild 打成 IIFE。`dist/app.js` 是自包含的，双击 `index.html` 直接能跑。

代价是改代码之后要重新 build。`npm run build` 已经挂在 `package.json` 里了。

## 已知问题

1. **迎风面积 A 是估的。** 1.6e-3 m² 来自同类车的经验区间，我们自己没有实测。这个数直接乘进阻力，所以绝对数值不可信，只有相对趋势可信。要修就得拿卡尺量车体正面投影。

2. **Cd0 也是估的。** 0.34 是钝体中值。真实值只能靠风洞或者滑行试验反推。

3. **sin² 修正只在中小迎角成立。** 超过 12° 会明显偏差，滑杆上限卡在 10° 就是为了不让人拖到失真区。

4. **流场是二维的。** 粒子在 x-z 平面上积分，y 只做了随机分布。所以侧视看着对，从正上方看会发现流线不闭合。

5. **尾流是假的。** 指数衰减 + 高斯扰动是为了视觉可读，没有对应的物理测量。它看起来像尾流，但它不是尾流。

6. **打包后 567 KB。** 主要是 three.js 本体。对本地使用无所谓，但它不是一个"轻量"页面。

7. **只测了 Chromium。** Firefox 和 Safari 没跑过。`ctx.letterSpacing` 是较新的 Canvas API，老浏览器会静默忽略（不会报错，只是字距不对）。
