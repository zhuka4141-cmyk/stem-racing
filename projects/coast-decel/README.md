# coast-decel · 烧完之后那 19 米

CO₂ 弹丸在 0.110 s 内把 1.47 N·s 的冲量全倒给车，然后就没劲了。
后面 19 米全靠惯性滑，车速从 18.35 掉到 16.91。这个页面就是把那段滑行拆开看：
速度怎么掉、掉在哪、风阻和滚阻各占多少。

---

## 我算的东西

滑行段只有两个力：

```
m_eff · dv/dt = −( ½ ρ Cd A v²  +  C_rr · m g )
```

`m_eff` 是等效惯性质量，不是天平上的质量——轮子要转起来也得吃能量：

```
m_eff = m + Σ I_w / r_w² = 0.065 + 4 × 4.5e−7 / 0.011² = 0.079876 kg
```

比静质量 65 g 重了 22.9%，这一项不加上，加速度会算高四分之一。

写成标准形式，`a = ½ρCdA / m_eff`：

```
a = 0.5 × 1.204 × 0.34 × 1.6e−3 / 0.079876 = 4.1000 × 10⁻³  1/m
b = C_rr · m g / (½ρCdA)   →   v∞ = √b
```

代进默认参数 `C_rr = 0.008`：

```
½ρCdA = 3.2749 × 10⁻⁴ kg/m
b     = 15.577 m²/s²      →  v∞ = 3.947 m/s
```

`v∞` 是渐近速度，不是终点速度。风阻 ∝ v²，滚阻恒定，两个力在 3.947 m/s 处打平；
低于这个速度滚阻一家说了算，车再也追不回来。

闭式解（`v(t)` 和 `x(t)`）跟 RK4 数值积分在 20 m 全程上的差 < 1e−6 m，
这是我唯一敢说"准"的地方——因为两个解是同一套方程推出来的，只是算法不同。

**整跑的分段：**

| 段 | 距离 | 时间 | 速度 |
|---|---|---|---|
| 推力段 | 1.0108 m | 0.1100 s | 0 → 18.3468 m/s |
| 滑行段 | 18.9892 m | 1.0784 s | 18.3468 → 16.9063 m/s |
| 合计 | 20.0000 m | 1.1884 s | — |

**阻力占比：**

| 位置 | 风阻 | 滚阻 | 风阻占比 |
|---|---|---|---|
| 刚烧完 18.35 m/s | 110.23 mN | 5.10 mN | 95.6 % |
| 终点 16.91 m/s | 93.60 mN | 5.10 mN | 94.8 % |
| v∞ 3.947 m/s | 5.10 mN | 5.10 mN | 50.0 % |

从 95.6% 掉到 50.0% 只发生在速度掉到 1/4.6 的时候，而 20 m 里速度只掉了 7.9%。
所以对这根车来说，**"低速时滚阻才重要"这句话在 20 m 内根本不成立**——它一直是 5% 左右的小角色。

## 图上能看出什么

**① v(t)。** 烧完点用橙线标出来，右边那段几乎水平的滑行就是全部内容。
纵轴从 15.4 起，因为从 0 起的话这段滑行会被压成一条贴顶的线，什么都看不见。

**② v–x 相图。** 横轴是位置，纵轴是速度。这段曲线是 `v = √(v₀² − ... )` 那种形状，
斜率直接就是 `dv/dx = −a(v² + b)/v`，在 20 m 处仍然很平，说明车还在"高速区"。

**③ 阻力占比随速度。** 风阻份额 `v²/(v² + b)` 在 3.947 m/s 处正好 50%。
这条曲线的横轴范围是 0–20，所以 20 m 的整段滑行只用了右边一小段，剩下 80% 的横轴是给
"如果车能一直滑下去"准备的。

## 已知问题

1. **`Cd = 0.34` 是从文献抄的，不是这辆车吹出来的。** 方背车身 Cd 在 0.28–0.42 之间都能见到，
   这个 ±20% 会直接平移整条 `v(t)`——终点速度大概 ±0.3 m/s，滑行距离差 ±0.5 m。
   我把它标成 `[TYPICAL]` 就是为了提醒自己：这个数没有我的数据支撑。

2. **`C_rr = 0.008` 是猜的，而且被当成常数。** 真实滚动阻力系数随速度略微上升
   （轮胎变形带来的黏弹损耗），低压胎在 0–5 m/s 段能差 30%。而低速端恰恰是滚阻主导的地方，
   所以图 ③ 那条 50% 线的横坐标位置，误差可能就是 0.5–1 m/s。

3. **完全没有轮轴摩擦和导向销摩擦。** 真车低速时有静摩擦和轴套阻力，量级能达到几 mN 到十几 mN，
   跟滚阻是同一档。这个模型里没有这一项，所以它算出来的 `v∞ = 3.947 m/s` 是"永远到不了的速度"，
   而真车在 3 m/s 以下会被这些干摩擦吃掉，5 秒内停住。**这是模型最实质的一个结构性缺陷**：
   我画了一条渐近线，现实是撞墙。

4. **Cd 当成常数，但 Re 在这段里变了 4.6 倍。** 从烧完的 `Re = 2.42×10⁵` 到终点的 `Re = 2.23×10⁵`，
   如果一路滑到 v∞，`Re` 只剩 `5.2×10⁴`——跨过了钝体绕流的分离点变化区间。
   `Cd` 在这个区间的真实变化可能有 ±15%，我这里一动不动。

5. **只把轮子转动折算成等效质量，没有滑动。** `m_eff = m + ΣI/r²` 这条式子前提是**纯滚动无滑移**。
   真车起步瞬间会打滑，刹车时也会，那部分能量直接变热，不在这个模型里。

6. **没有俯仰和侧倾。** 车在滑行中重心会前后移（尤其刚烧完那一下），抬头会改迎风面积，
   侧倾会把 `A` 抬起来。我全当刚体平移处理，`A` 是一个固定的数。

7. **没有终点海绵，所以数学上永远不停。** 赛道上 20 m 末端有块海绵，车 3 ms 内停住。
   这个模型里 `x = 20 m` 只是一个记账点，车从那里继续跑（图 ③ 的横轴就跑到 0 m/s）。
   图上那条 v∞ 渐近线，物理上是不存在的。

8. **推力段的初始状态是数值积分出来的，没有高速摄影对过。** `0.110 s / 1.0108 m / 18.3468 m/s`
   这三个数是从冲量和推力曲线积分来的，只要冲量偏 5%，后面 19 米全歪。
   我唯一的外部校验是"整跑 1.1884 s 落在 1.00–1.25 s 的合理带里"，这只能说明没离谱，不能说明准。

9. **ρ 只按 20 °C 取，没考虑赛道温度。** 15–35 °C 会让 ρ 变 ±3.5%，方向跟 `Cd` 的误差相反，
   两者部分抵消——但这纯属运气，不是我算出来的。
