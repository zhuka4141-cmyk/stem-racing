# friction-loop · 前轮摩擦圆

一句话：把一台 CO2 直线加速车的**前轮接触斑**画出来，看纵向力和侧向力怎么共用同一份摩擦。

## 为什么做这个

我们的车在第一次试跑时车头往左摆，撞上导轨销。当时队里的一致判断是"轮子没装正"，
换了三套轮轴都没用。后来拿弹簧秤压着车头推了一下才反应过来：真正的问题是
**质心横向只偏了不到半毫米**。

这件事没法用嘴讲清楚——你说"偏一点没事"，别人就真敢装偏两毫米。所以我把它做成了
一张图：左边是摩擦圆，右边是俯视示意，中间一根滑杆拖质心偏移，
使用率会从 30 % 一路走到 100 % 以上。

## 这块的物理

单个前轮接触斑上，纵向力 F_x 和侧向力 F_y 共用同一份摩擦：

    |F| = sqrt(F_x² + F_y²) ≤ μ·N_w

所以极限是一个圆（摩擦圆），不是两条独立的线。半径就是 μ·N_w。

前轴法向力（静态）：

    N_f = m·g·(1 − comFrac) = 0.065 × 9.81 × (1 − 0.55) = 0.2869 N
    N_w = N_f / 2 = 0.1435 N

摩擦圆半径：

    μ·N_w = 0.60 × 0.1435 = 86.08 mN

侧向力从哪来——推力线相对质心横向错开 d，产生偏航力矩 M = F·d，
两个前轮用侧向摩擦顶住，力臂是"导轨销到前轴"的 37.5 mm：

    f_y = F·d / (2 × arm) = 21 × d / 0.075

也就是**质心每偏 0.1 mm，每个前轮多背 28 mN 的侧向力**。

临界偏移就是 f_y 刚好等于 μ·N_w 的地方：

    d_crit = μ·N_f·arm / F = 0.60 × 0.2869 × 0.0375 / 21 = 3.074×10⁻⁴ m = 0.307 mm

默认状态取 d = 0.30 mm，使用率 97.6 %——**差 0.007 mm 就吃满**。

底部整跑成绩用同一份参数组积分出来（RK4，dt = 0.5 ms）：20 m / 1.1885 s，
末速 16.906 m/s，峰值 18.347 m/s 出现在 t = 110 ms（烧完那一刻）。
推力是半正弦脉冲 21 N × 110 ms，冲量 I = 2F·t/π = 1.4706 N·s，
除等效惯性质量 79.876 g 得 18.411 m/s——实测积分只有 16.906，中间的 8.2 % 被阻力吃掉了。

## 怎么用

三个滑杆：

- **质心横向偏移 d**（0–0.60 mm）：就是中间那个。超过 0.307 mm 曲线和扇形一起变橙。
- **前轮前束角**（0–5°）：前束每度产生 μ·N_w·sin θ 的刮擦阻力，占纵向力，
  横轴上那一点点长度会变长。
- **轮轨摩擦系数 μ**（0.35–0.90）：直接改圆半径，也直接改 d_crit，成线性。

## 已知缺陷

这是这个项目最该看的部分。图上每个结论都有前提，前提不成立结论就不成立。

1. **μ 是文献中值，不是我们测的。** 取 0.60，但钢轨和聚氨酯轮在赛道上的
   实际值可能在 0.4–0.9 之间。d_crit 对 μ 是线性的，μ 从 0.6 掉到 0.45，
   临界偏移就从 0.307 mm 变成 0.230 mm，整条结论差 25 %。赛前用弹簧秤做一次
   牵引打滑试验就能把这个数定下来，我们还没做。

2. **推力线高度差 dh 直接取 0。** `N_f = mg(1−comFrac) + F·dh/L_wb` 里第二项是
   俯仰载荷转移。CO₂ 气瓶轴线大致在质心上方 8–10 mm，21 N 的推力会产生
   约 1.4–1.6 N·m/0.13 m ≈ 11–12 N 量级的附加轴荷——这一项比静态轴荷大几十倍，
   我直接扔了。这是全模型里最可疑的一处简化。

3. **两个前轮平摊侧向力是假设。** f_y = F·d/(2·arm) 要求两侧轮子刚度和载荷完全对称。
   实际装车时左右轮荷差个 5 % 很正常，先到极限的永远是一侧，所以真实 d_crit
   应该比 0.307 mm 更小。图上给的是理想对称值。

4. **摩擦圆假设各向同性。** μ_x = μ_y = μ。橡胶/聚氨酯的纵向附着系数通常比侧向高
   10–20 %，真实边界是个椭圆不是圆。按圆算会把侧向余量算得偏大。

5. **完全没算陀螺效应。** 末速 16.9 m/s 时每只轮子角速度 1537 rad/s，
   四只轮子的总角动量约 2.8×10⁻³ kg·m²/s。车体偏航时会反过来被这个角动量顶住，
   量级和抗偏航上限 6.46 mN·m 是同一档，不能忽略。加上这一项 d_crit 会变大（更稳），
   所以现在这张图对"摆不摆"的判断偏保守。

6. **打滑判据是准静态的。** 判据是 |F| > μN_w 这一个瞬时不等式，
   但"越过后车头摆多少"取决于响应时间。图上只能说越过就危险，
   说不出"摆 3 毫米还是 30 毫米"。

7. **只画了单个前轮。** 后轮完全没进模型。后轮侧滑的表现是甩尾，
   和车头摆是两种失效，这里一种都没覆盖。

8. **温度、粉尘、轨道清洁度都不在模型里。** 比赛当天第一趟和第三趟的 μ 不一样，
   这个项目假装它一样。

## 自检

`tests/gate.mjs` 会调 `window.__app.selfTest()`，里面是 11 条可证伪的断言，例如：

- 摩擦圆半径 ∝ μ（μ 加倍半径加倍），比值误差 < 1e-12
- d = d_crit 处 F_y 恰好等于 μN，偏差 < 1e-9
- 两条独立路径（侧向力需求 / 偏航力矩上限）算出的 d_crit 必须一致
- 前束刮擦力 ∝ sin θ，不是 ∝ θ
- 参数组自洽：冲量、动量、距离、平均速度四条互相对得上

任何一条挂了 `selfTest()` 返回 ok = false，门禁直接红。
